# 書き文字（擬音）のスタイル

- いつ読むか: 擬音・描き文字を層で置くとき（`lettering-layers.md`）、AI にスタイルを選ばせるとき、スタイルを足すとき。
- いつ読まないか: 擬音の中身（どの音を、どのコマに、どれだけ）を決めるとき。それは `manpu.md` の 4 系統（擬音）と `dialogue-and-lettering.md` §9。

描き文字は「読ませる」より「感じさせる」文字で、音の質（重い・鋭い・柔らかい・不気味）を形で伝える。`scripts/typeset.py` の 19 のスタイルは、フリーフォント（すべて SIL OFL）に加工（フチ・斜体・字ごとの揺れ・だんだん大きく・震えの残像・立体の影・残響・速度の尾）を組み合わせたもの。見本は `assets/sfx/sfx-styles.png`（網点の上に置いたもの。白フチの効き方が分かる）。

## 2. 作り方の元にしたもの

CLIP STUDIO ASSETS の無料の描き文字ブラシ（人気順、2026-11 時点）の傾向を**参考に**した。ブラシ・素材そのものは使っていない（絵柄・形を写さず、傾向だけを書体と加工に置き換えた）。

| ブラシの傾向 | このスキルのスタイル |
|---|---|
| 描き文字マーカー（勢いのある手書き） | `marker` |
| べちょ筆・筆文字（にじむ太筆） | `brush`、`syuku` |
| SE 文字ペン（角ばった鋭い線、速さ） | `sharp` |
| 横太の描き文字 | `wide` |
| ふちペン・二重ふち・袋文字 | `pop`、`wide`、`impact`、`block` |
| ぽてぽて・ぽてカク（丸く弾む） | `pote`、`pop` |
| 手書きのセリフ用ペン（細い） | `pen`、`soft` |
| つる丸筆・丸文字 | `cute` |
| 震え・ホラー | `tremble` |

## 3. 選び方

- **音の重さで選ぶ。** 重い衝突・爆発 → `impact` `block` `wide`。鋭い・速い → `sharp`。柔らかい・弾む → `pote` `pop`。かすかな物音 → `pen`。
- **場面の空気で選ぶ。** 不穏・強者 → `menace`。恐怖 → `tremble`。ときめき → `cute` `pulse`。ほのぼの → `soft`。和風・余韻 → `syuku` `brush`。無音・間 → `quiet`。機械 → `digital`。
- **1 ページで 2〜3 種まで。** 同じ音の質には同じスタイルを使い続ける（作品の中で「この音はこの形」を覚えさせる）。
- **大きさで強さを出す。** スタイルを強くするより、決めのコマで大きく・斜めにするほうが効く（`lettering-layers.md` §3 の `size`）。小さな物音を大きなスタイルで描かない。
- **ベタ・暗い背景の上**は `color: "white"`（白抜き）にするか、`train`（抜き文字）を使う。
- **縦書きが基本**（実際の漫画の擬音の 83% が縦、`corpus-norms.md` §7）。横に流れる動き（横切る・走り抜ける）は横書きにする。

## 4. スタイルを足すとき

`scripts/typeset.py` の `STYLES` に 1 項目足す。書体を足すなら `scripts/data/fonts.json` に Google Fonts（OFL）の URL とライセンスの URL を書き、`fetch_fonts.py` で取る。項目の意味は `STYLES` の上のコメント。足したら `typeset.py sample` で見本を作って、網点の上で白フチが効いているか、字が潰れていないかを見る。

足りない字（漢字の無い書体など）は、Dela Gothic One・しっぽりアンチック B1・Mochiy Pop One の順で補う。

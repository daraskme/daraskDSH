# 写植・演出の層（絵に描かせない文字と効果）

- いつ読むか: コマの絵ができた後に、吹き出し・台詞・書き文字（擬音）・作中の文字・効果線・漫符を載せるとき。AI に層を置かせるとき。`typeset.py` / `page_compose.py` を使うとき。
- いつ読まないか: ネームの段階（台詞と演出の中身は `dialogue-and-lettering.md`・`manpu.md`・`staging.md` で決める）。

このやり方では、画像モデルに描かせるのは**人物と背景だけ**にする。文字と線の演出は、AI（または人）が絵を見てから「層」として上に置く。層は `scripts/typeset.py` が SVG に組み、文字はフォントの輪郭（パス）になるので、どの端末で開いても、PNG にしても同じに見える。

## 1. なぜ絵と層を分けるか

- **文字が化けない。** 日本語の台詞を画像モデルに描かせると、誤字・縦書きの崩れ・読み順の入れ替わりが出る（`dialogue-and-lettering.md` §10）。層ならネームの文字列そのものが入る。
- **直しが安い。** 台詞や擬音の位置・大きさを変えても絵を描き直さなくてよい。絵を描き直しても、層はそのまま使える。
- **演出の強弱を後から決められる。** 集中線・フラッシュを絵の出来を見てから足す・抜く。絵に既に線があれば足さない。
- **絵が良くなる。** 画像モデルは、文字や吹き出しや効果線を指示されないほうが人物と背景に集中する。プロンプトの長さの上限（Anima の T5 は 512 トークン）にも余裕ができる。

逆に、層では描けないもの（顔・体の表情や質感）は絵に残す。

## 2. 絵に残すもの・層に回すもの

| もの | 行き先 | 備考 |
|---|---|---|
| 人物、ポーズ、表情、服、背景、小物 | 絵 | ネームの `visual`・`pose`・`expression`・`place_en` |
| 顔・体そのものの漫符（赤面、涙、ぐるぐる目、白目、目元の影、青ざめ、震え線、汗ばみ、よだれなど） | 絵 | 線を重ねても顔にならないもの |
| 体の動きの線（動線、残像、動作の弧）、土煙、水しぶき、放電 | 絵 | 形が体に沿うもの |
| 台詞・心の声・ナレーション・モノローグ（吹き出しごと） | 層 `balloon` | 文字はネームのとおり |
| 擬音・描き文字 | 層 `sfx` | スタイルは `sfx-styles.md` |
| 作中の文字（看板・画面・手紙）、欄外の小文字 | 層 `text` | 遠近に沿わせたいときだけ絵に回す |
| 画面の線の演出（集中線、ベタフラ、ウニフラ、スピード線、縦線、衝撃、強調線、雨、雪、紙吹雪、花びら、光の筋など） | 層 `effect` | 一覧は `scripts/data/overlay.json` |
| 頭のまわりの漫符（汗、！、？、怒りマーク、音符、ハート、キラキラ、ひらめき、もやもや、Zzz など） | 層 `mark` | 一覧は同上 |

`name_layers.py`（と `name_export.py --to anima`）は、層に回すものをコマのプロンプトから外し、ネガティブに `text, letters, speech bubble, sound effect lettering` を入れる。

## 3. 層の書式

座標はコマの中の割合（x は幅、y は高さに対して 0〜1、左上が 0,0）。コマの縦横比（`aspect` = 横/縦）は `name_export.py --to layers` が出す。吹き出しと書き文字は、コマの外へ 0.15 まで出せる（枠越え）。効果はコマの中で切る。

```json
[
 {"type":"balloon","style":"speech","lines":["……どこが"],"x":0.565,"y":0.035,"w":0.095,"h":0.31,"tail":[0.705,0.385]},
 {"type":"sfx","text":"ダンッ","style":"impact","x":0.875,"y":0.44,"size":0.095,"vertical":true,"rotate":8},
 {"type":"text","text":"パティスリー・ミモザ","x":0.05,"y":0.05,"size":0.04,"vertical":false},
 {"type":"effect","name":"focus_lines","cx":0.6,"cy":0.4,"r":0.3,"angle":0,"density":1},
 {"type":"mark","name":"sweat_drops","x":0.3,"y":0.12,"size":0.08,"rotate":0}
]
```

| type | 項目 |
|---|---|
| `balloon` | `style`: speech（ふつう）/ shout（トゲ）/ whisper（点線）/ thought（雲）/ narration（四角）/ monologue（枠なし）。`lines`: 縦書きの列（右の列から）。`x,y,w,h`: 吹き出しの箱。`tail`: しっぽの先（話者の口元）。口元が吹き出しの際より内側ならしっぽは描かない。`size`: 字の大きさの倍率（既定 1。字は箱に収まる大きさに自動で決まる） |
| `sfx` | `text`、`style`（`sfx-styles.md`）、`x,y`: 1 字目の左上、`size`: 字の高さ（コマの幅に対する比。小さな物音 0.05〜0.08、普通 0.1〜0.16、決め 0.2〜0.35）、`vertical`、`rotate`（度）、`color`: black / white（ベタの上は white） |
| `text` | `text`（改行は ／）、`x,y`、`size`（0.03〜0.06）、`vertical`、`style`（任意。書き文字のスタイルの書体を使う） |
| `effect` | `name`、`cx,cy`: 中心、`r`: 中心を空ける半径（コマの幅に対する比）、`angle`: 流れの向き（度。スピード線・風）、`density`: 0.2〜3 |
| `mark` | `name`、`x,y`、`size`（0.05〜0.12）、`rotate` |

字の書体: 台詞はアンチック体（しっぽりアンチック B1）、叫びは太ゴシック（Dela Gothic One）、ナレーション・モノローグは明朝（Zen Old Mincho）。`dialogue-and-lettering.md` §9.2 の 3 書体に合わせてある。

## 4. 置き方の約束

1. **台詞の文字はネームのとおり**（句読点・…・！？を含む）。列の分け方は変えてよい（`dialogue-and-lettering.md` §2）。台詞を足したり言い換えたりしない。ネームの台詞は全部どこかの吹き出しに入れる。
2. **吹き出しは、顔・目・手元・決めの動作・見せたい物に重ねない。** コマの中の読む順（右上 → 左下、右綴じ）に、話す順で並べる。話者の近く、多くは頭の上（`corpus-norms.md` §7）。しっぽの先は話者の口元。
3. **吹き出しの大きさは文字量に合わせる。** 1 列およそ 4〜9 字。字を小さくして詰めない（`dialogue-and-lettering.md` §9.2）。
4. **書き文字は、音の出どころと動きに沿わせる。** 場面に合うスタイルを選び（`sfx-styles.md`）、顔にはかけない。決めのコマでは大きく、角度をつけてよい。小さな物音は小さく。
5. **演出は、ネームの `effects` と、beat を強めるときだけ。** 集中線・フラッシュの中心は見せたいもの、`r` は主題（顔・手）を覆わない大きさ。絵に既に線があれば足さない。全部のコマに線を足すと、どれも強調されなくなる（`art-direction.md`）。
6. **漫符はネームの `manpu` を、その人物の頭の横・上に。** 感情を言い当てる程度に小さく。
7. **絵の無いコマ**は、ネームと人物の位置（右・中央・左）から推定して置き、絵ができたら置き直す。

## 5. AI に置かせる手順

1. `name_export.py name.toml --to layers --out layers.json` で、コマの縦横比と層の叩き台（`manga_name.place_panel` の推定配置）を出す。
2. 各コマの絵を、コマの縦横比で中央から切り抜く（コマ枠には cover で入るので、見えるのはその範囲）。
3. 画像を読めるモデル（Claude Code の Read など）に、切り抜いた絵・ネームのコマ（beat・人物・台詞・効果・漫符）・叩き台の層・§3 の書式・§4 の約束・`dialogue-and-lettering.md`・`sfx-styles.md` の一覧を渡し、**絵を見て顔・手・見せたい物の位置を確かめてから**層を置かせる。出力は `{"panels":[{"id":…,"layers":[…]}]}`。
4. 返った層を検める（知らない type・名前を落とし、数値を範囲に収める）。
5. `typeset.py` で SVG にし、絵に重ねて確かめる。直すのは層だけ。

実際に AI に置かせた例: 鷹野が台を叩いて迫るコマで、吹き出しは二人の顔の間（しっぽは鷹野の口元）、「ダンッ」は叩いた手の横に縦に置き、絵に既に集中線があったので効果は足さなかった。

## 6. 道具

| スクリプト | 役割 |
|---|---|
| `name_export.py --to layers` | コマの縦横比と層の叩き台（JSON） |
| `name_export.py --to anima [--prefix …]` | 層に回すものを外した、コマごとの絵のプロンプトとネガティブ（JSON Lines。Anima の 512 トークンに収める） |
| `typeset.py panel layers.json --aspect A --out panel.svg` | 1 コマの層を SVG に。`styles` で書き文字のスタイルと描ける効果・漫符の一覧、`sample OUT` で見本 |
| `page_compose.py name.toml --images DIR [--layers layers.json] --out DIR [--png]` | ページを組む（絵を枠に切り抜き、枠線、層）。SVG、あれば PNG |
| `make_cbz.py OUT.cbz p*.png --title 題名` | ページを CBZ に（右綴じ・白黒の ComicInfo.xml つき） |
| `fetch_fonts.py` | フォント（すべて SIL OFL）を `MANGA_FONT_DIR`（既定 `.fonts/`）に取る |

`typeset.py`・`page_compose.py` には fonttools と uharfbuzz が要る（`pip install fonttools uharfbuzz`）。他のスクリプトは標準ライブラリだけで動く。

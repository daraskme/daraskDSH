# コマ割りの型の保存庫（layout-library）

- いつ読むか: 1 ページを割るとき、場面に合う型を探すとき。気に入ったコマ割りを保存したいとき。
- いつ読まないか: 話とページ配分を決める前（`story.md` が先）。型から話を作らない。

型は `scripts/data/layouts.json` にあり、`scripts/layout_library.py` で引く。一覧の絵は `assets/layouts/layouts.png`（コマ枠と読む順だけ。薄い青ははめ込み）。型ごとの図（`assets/layouts/svg/`・`png/`）と解説（`assets/layouts/text/`、場面から引く索引は `assets/layouts/README.md`）は `scripts/layout_assets.py` で書き出す。

```
python scripts/layout_library.py list [--kind common|rare|user] [--panels N] [--scene talk|action|gag|emotion|tense]
python scripts/layout_library.py show C14          # 目的・場面・使われ方・コマごとの中身・避けるとき・根拠と、ネーム TOML の雛形
python scripts/layout_library.py preview out.html  # 型をネーム画像で並べる（ID を並べれば一部だけ）
python scripts/layout_library.py add U02 --name "名前" --boxes "[[x1,y1,x2,y2], ...]" --why "狙い" --scenes emotion
```

`show` の雛形は、段（`tiers`）・幅（`width`）・縦に積む組（`column` / `height`）で書ける型はそれで、重なり・はめ込み・段からずれた位置・コマの間の大きな空白（60/1000 を超える）・外側の余白のある型は `bbox` と `order = "written"` で出す。各コマには「役割の目安」と `shot` の目安がコメントで入る。目安は実際の漫画での傾向で、決まりではない。人物・台詞・`detail` はコマごとに足す。

## 使い方

1. 先に、このページの見せ場（いちばん大きいコマ）と、場面の種類と、右ページか左ページかを決める。
2. `list --scene` と `--panels` で候補を 2〜3 個出す。場面には根拠が付く: 「観測」は実際の漫画で多かった場面、「観測・少数の作品」は 4〜7 冊だけで多かった場面、「目的から」「構図から」は型の作りから考えた候補。
3. `show` で「目的」「使われ方」「コマごとの中身」を見て選ぶ。根拠が「強い」「中」の型は実際の漫画で広く使われている。「弱い」「実例ほぼなし」の型は、構図の理屈で選ぶ。
4. 雛形を貼り、コマごとに `beat` `shot` と人物・台詞を書く。`detail` と `background` は、台詞とコマ割りが決まった後、ネームの最後の工程で付ける（`art-direction.md` §1・§3）。役割の目安と違う使い方をしてよい。そのときは理由を `note` に書く。
5. 同じ型を続けて使わない（実際の漫画で、隣のページと同じ割りは 1.4%）。rare の型は 1 話に 1〜3 回、見せ場のページに。
6. 寸法は叩き台。大きさの比（`tiers` と `width`）は、見せたいコマに合わせて動かす。

## 0. どう調べたか

- **型の形:** common は、manga lora の注釈（Manga109-s 由来の承認済み 6,681 ページ）で、段の積み重ねとして解けたページを形ごとに束ね、多い順に 30 個取った寸法の中央値。rare は同じ注釈から、重なりのあるページや同じ形が 2 ページ以下のページを 96 枚無作為に引き、コマ枠の線だけの図を見て構図の狙いが読み取れるものを選んだ。user は作者が足した型。
- **実例の当てはめ:** Manga109-s 全 87 冊のストーリー漫画 15,458 ページ（4コマの 2 冊を除く。見開きはノドで左右に割った）を、保存した型に当てはめた。手順は次のとおり。
  1. ページのコマ枠を、コマ全体の外枠が 0〜1000 になるように縦横それぞれ引き伸ばす（型の座標と同じ）。
  2. コマ数が同じ型だけを候補にし、型の各コマとページの各コマを、枠の重なり（IoU）の大きい組から 1 対 1 で貪欲に対応づける。対応した組の IoU の平均をその型の得点にする。
  3. 得点が最も高い型 1 つに割り当てる（同点なら `layouts.json` で先の型）。得点が 0.6 未満ならどの型にも数えない。1 コマのページは C01。
  4. 結果、4,653 ページ（30%）が当てはまった。1 ページは 1 つの型にだけ数えた。形の近い型（例: C04 と C17 は同じ位置のコマどうしの IoU が平均約 0.78）では、ページはより近いほうに入る。
- **コマの中身:** 台詞・顔・体・擬音は、その中心を含むいちばん小さいコマ 1 つにだけ数えた（はめ込みと下の大ゴマに二重に数えない）。ショットは近似の分類で、主な人物（体の枠がいちばん高い人物）の「見えている体に対する顔の高さの割合」で決めた: 0.55 以上は顔の寄り、0.33 以上は胸から上、0.18 以上は腰から上、それ未満は全身（体がコマの高さの 45% 以上）か引き。顔だけの人物は顔の大きさをコマの短い辺に対して、体だけ（後ろ姿など）は体の高さで決めた。全体では、顔の寄り 15%、胸から上 22%、腰から上 31%、全身 8%、引き 6%、人物なし 18%。無言のコマ（台詞が 0）は 23%、一人のコマは 46%、二人以上は 36%。
- **場面の種類:** 公式の注釈に無いので、承認済みページの要約の英文から語で拾った粗い分類（会話・動き・ギャグ・感情・恐怖・扉）。全体より 1.3 倍以上多く、8 冊以上の作品で出たものを「多い」、4〜7 冊のものを「やや多い（ただし n 冊だけ）」とした。3 冊以下は書かない。読者層も同じく、1.5 倍以上で 8 ページ・4 冊以上なら「多い」、それ未満は「やや多い（ただし n ページ・m 冊だけ）」、2 冊以下は書かない。
- **根拠の強さ:** 型全体の実例の広さの区分。実例 100 ページ以上・40 冊以上で、1 冊の作品が 2 割以下なら「強い」。30 ページ・15 冊以上なら「中」。10 ページ以上なら「弱い」。それ未満は「実例ほぼなし」で、コマごとの数字は出さず、場面は構図の理屈から書いた候補。個々の「使われ方」の行は、それぞれに付けた冊数・ページ数で読む。
- **限界:**
  - 当てはめは形の近さだけで見ている。斜めのコマ、はめ込みの多いページ（全体の 42% は段にきれいに収まらない）は、どの型にも当てはまりにくい。
  - ショットは枠の大きさからの推定で、絵を見ていない。体の枠がコマで切れていると、実際より寄りに出ることがある（逆もある）。コマの形との関係（例: 横長の帯に顔の寄りが多い）は、絵を目で確かめていない。
  - 数字は「その型のページで、全体より多かった」という観測で、その割りにすると効果が出るという因果は測っていない。手で書いた「目的」は、観測と構図の理屈から作った使い方の案。
  - Manga109-s は 1970〜2010 年代の作品で、今の作品の傾向とは違うことがある。

## 1. 分かったこと（型をまたいで）

1. **横長の帯は、顔の寄りが多い。** 大ゴマの前後に置く細い横長のコマ（C02・C05・C07・C10 の 2 コマ目、C09 の 3 コマ目、C14・C27 の 4 コマ目）は、顔の寄りが 29〜38%（全体 15% の 1.9〜2.5 倍）。ページの最後に置く帯でも C24 の 4 コマ目は 17% で、胸から上と台詞が多い。帯は、目元や反応の顔を入れる候補になる。
2. **大ゴマは、顔より全体。** ページでいちばん大きいコマ（3 コマ以上のページ）は、顔の寄りが 10%（ほかのコマは 16%）、全身・引きが 24%（ほかは 12%）、二人以上が 45%（ほかは 34%）、擬音が 0.69 個（ほかは 0.50 個）。下に置く大ゴマ（C12 の 2 コマ目、C13 の 3 コマ目）は全身が全体の 3.4〜3.5 倍。最後の大ゴマに二人以上を入れる型（C22 の 5 コマ目 58%、C23 の 4 コマ目 60%）もある（`corpus-norms.md` §6）。
3. **溜めの小ゴマは、無言が多く、二人以上が少ない。** C28 の上の 3 コマは無言が 32〜42%（全体 23%）。2・3 コマ目は一人が 62〜63%、二人以上は 11〜12%、人物なしが 26%。台詞のあるコマも 6 割ほどあるので、無言は「全体より多い」程度。一人か物の小さな絵で溜める作りは、候補の一つ。
4. **均等な会話劇は、二人以上と台詞。** C20 は 6 コマとも二人以上が 45〜56%、無言は 12〜19%。
5. **めくった先は、上に大ゴマ。** C08（65%）・C02（61%）・C13（61%）は右ページ（めくった先）で多い。1 枚絵の C01 も 59%。全ページで見ると差は小さい（`corpus-norms.md` §6）。
6. **単行本の終わりは、大きく静かに。** C01・C03・C12・C13・C22 と縦 3 分割の R04 は、終わり 1 割で多い（13〜17%、全体 8%）。

## 2. よく使う型（common）

### C01  1 コマ（扉・見せ場の 1 枚）  （common、1 コマ、実例 524 ページ・72 冊、根拠: 強い）

```
目的: 1 枚で見せる。扉、章の頭、話の最大の見せ場。4 枚に 1 枚は人物のいない情景で、無言が多い。
場面: 感情・恋愛・静けさ（目的から）、動き・戦い・スポーツ（目的から）
使う場面（実際の漫画での使われ方）:
  - 扉・章の頭の場面で多い（3.7 倍、24 冊）
  - 単行本の終わり 1 割で多い（14%、全体 8%）
  - 場面の頭に向く（1 コマ目が引きか人物なしのページが 39%、全体 28%）
  - 女性漫画で多い（1.5 倍、107 ページ・9 冊）
  - 1 ページの台詞は平均 1.57（全体 7.7）
コマごとの中身（読む順）:
  1. 人物なし（物・景色・手元）が全体より多い（25%、全体の 1.4 倍）、無言が全体より多い（35%、全体 23%）
避けるとき: 会話の途中。続けて使うと間延びする。次のページは多コマに戻す。
```

## 4. 作者が足した型（user）

### U01  引きの導入 → 枠なしの決め → 小さく受ける  （user、3 コマ、実例 7 ページ・5 冊、根拠: 実例ほぼなし）

```
目的: 1 コマ目で場所と人物を小さく見せ、ナレーション箱で状況を一言。2 コマ目は枠を外した決めコマ（detail = "key"）で、人物と手元を大きく。3 コマ目は横長の小さなコマで、受けの反応を軽く（detail = "light"）。2026-11-15 の比較画像の「工夫した版」から。
場面: 会話・説明（構図から）、感情・恋愛・静けさ（構図から）
（場面は構図・目的から考えた候補で、実例の数字の裏付けは無い）
避けるとき: 会話の多いページ。3 コマで運べる台詞は少ない。
```

自分の原稿や、気に入ったネームの割り方は `add` で足す。`boxes` は、コマを並べる範囲を 0〜1000 にした `[x1, y1, x2, y2]` を読む順に。既存の漫画のページから足すときも、保存されるのは枠の座標だけで、絵や台詞は入らない。良い型が見つかったら、`--why` に「何のためにこう割るか」を一文で残す（`purpose` に入る）。理由の無い型は、次に使うとき選べない。足した型には実例の数字は付かない。

# 場面別のコマ割りパターン（こういうときは、このコマ割りが強い）

- いつ読むか: ネームを切る直前、場面の種類が決まったとき。下の表で当たったパターンだけを 1〜3 個開く。
- いつ読まないか: 企画・プロットの段階。全パターンを通読しない（全ページに型を当てると、どのページも同じ味になる）。原則（読み順、めくり、タチキリ、間）は `paneling.md`。
- パターンはそのまま貼らない。人物・場所・小物の名前を入れて、この場面だけのコマ割りに直してから使う。直前の場面で使った型は、次の場面では避ける。
- 図の数字は読む順（右綴じ: 段を上から下、段の中は右から左）。比率と枚数は目安。出典のある型には URL を付け、無いものは慣習にもとづく目安として書いた。
- 「骨格」は TOML の短縮形（`panels = [{...}, ...]` は `[[pages.panels]]` を並べるのと同じ意味で、`tomllib` で読める）。台詞や人物は展開した形で書き足す。値の語彙は `scripts/manga_name.py`（shot・angle・transition）と `scripts/data/manpu.json`（漫符・効果）。

## 01 掴みの 1 ページ目

- こういうとき: 読切・第 1 話の 1 ページ目。誰の、どこの、何が起きそうな話かを数コマで渡したい。
- 形（型: 引き → 寄り → 違和感）:

```
┌─────────────────────────┐
│            1            │  情景の引き（タチキリで広さ）
├────────────┬────────────┤
│     3      │     2      │  主人公の姿 → 顔
├────────────┴────────────┤
│            4            │  違和感・問い（ページを読み進める理由）
└─────────────────────────┘
```

- ショット: 1 `extreme_long` か `long` / `high` → 2 `full` / `eye`（`subject`）→ 3 `bust` か `closeup`（`action`）→ 4 `insert` か `medium`（`subject`）
- なぜ効くか: 場所（1）→ 人（2・3）→ 問い（4）の順は、読者が状況を組み立てる順と同じ。冒頭 6 ページまでに魅力が無いと読者が離れる（大今良時、https://www.clipstudio.net/oekaki/archives/152311 ）。1 ページ目の最初に目が行くコマが特に重要（https://www.cmoa.jp/cmoacomics/pickup/post-51-9.html ）。
- 文字・漫符・効果: 1 にナレーションを置くなら 1 つ、短く（場所と時だけ）。説明はしない。4 は台詞より絵の違和感で引く（落ちている手紙、鳴らない時計）。
- よくある失敗: 1 コマ目から主人公のバストアップで、場所が分からない（P03・P11）。ナレーションで世界観を説明し、絵が背景画像になる。4 コマ目で問いの答えまで出してしまう。
- 骨格:

```toml
tiers = [0.4, 0.3, 0.3]
panels = [
  {tier = 0, shot = "long", angle = "high", bleed = "top", scene = "s1", place = "", beat = ""},
  {tier = 1, width = 0.5, shot = "full", transition = "subject", beat = ""},
  {tier = 1, width = 0.5, shot = "bust", transition = "action", beat = ""},
  {tier = 2, shot = "insert", transition = "subject", beat = ""},
]
```

## 02 キャラ初登場（シルエットから）

- こういうとき: 強い人物、謎の人物、ライバルを印象づけたい。読者に「誰だ」と思わせてから顔を見せたい。
- 形:

```
┌────────┬────────────────┐
│   2    │       1        │  1 逆光のシルエット / 2 一部（目・手・武器）
├────────┴────────────────┤
│                         │
│            3            │  全身か顔の大ゴマ（めくりの直後なら最強）
│                         │
└─────────────────────────┘
```

- ショット: 1 `full` / `low`（逆光、`background = "black"` や `effects = ["black_background"]`）→ 2 `extreme_closeup`（`action`）→ 3 `full` か `closeup` / `low`（`moment`）
- なぜ効くか: 情報を一段ずつ明かすと、読者は空白を自分で埋めながら待つ。見せる直前で止めるので、3 の大ゴマに視線が溜まる。
- 文字・漫符・効果: 1 か 2 で名前や声だけを先に出す（`offscreen = true` の台詞）。3 に決め台詞を置くなら短く。3 の背景に `focus_lines` か `uni_flash`。
- よくある失敗: 1 から顔が見えている。毎回の登場を同じ型にする（同じ人物の 2 回目以降は普通に出す）。3 に説明台詞を詰める。
- めくりと合わせる: 1・2 を左ページの最後に、3 をめくった右ページの 1 コマ目に置くと、正体がめくりの見せになる（`paneling.md` 5 節）。
- 骨格:

```toml
tiers = [0.35, 0.65]
panels = [
  {tier = 0, width = 0.65, shot = "full", angle = "low", background = "black", beat = "逆光のシルエット"},
  {tier = 0, width = 0.35, shot = "extreme_closeup", transition = "action", beat = "目だけ"},
  {tier = 1, shot = "closeup", angle = "low", transition = "moment", effects = ["focus_lines"], beat = "顔"},
]
```

## 03 キャラ初登場（足元から）

- こういうとき: 堂々とした登場、日常の中の非日常な人物（転校生、上司、刺客）。
- 形: 縦に割った組で、足元 → 手元 → 顔を下から上へ追い、左の縦長コマで全身。

```
┌──────────┬──────────────┐
│          │      1       │  足元（靴・裾）
│          ├──────────────┤
│    4     │      2       │  手元（持ち物）
│ 全身の   ├──────────────┤
│ 縦長     │      3       │  顔
└──────────┴──────────────┘
```

- ショット: 1 `insert` / `low` → 2 `insert`（`action`）→ 3 `closeup`（`subject`）→ 4 `full` / `low`（`aspect` か `moment`）
- なぜ効くか: 持ち物と身なりで「どういう人か」を台詞なしに渡せる。縦長の全身は高さと存在感を作る（`paneling.md` 3 節）。
- 文字・漫符・効果: 周りの反応（ざわめき、`type = "aside"` の小文字）を 4 に。本人の第一声は次のコマに回すと溜まる。
- よくある失敗: 持ち物が話に関係しない（選んだ物はあとで使う）。全身のコマが小さい。
- 骨格:

```toml
tiers = [1.0]
panels = [
  {tier = 0, column = 1, width = 0.6, shot = "insert", angle = "low", beat = "足元"},
  {tier = 0, column = 1, shot = "insert", transition = "action", beat = "手元"},
  {tier = 0, column = 1, shot = "closeup", transition = "subject", beat = "顔"},
  {tier = 0, width = 0.4, shot = "full", angle = "low", transition = "moment", beat = "全身"},
]
```

## 04 会話の往復（切り返し）

- こういうとき: 二人の会話が中心の場面。説得、口論、打ち明け話。
- 形（型 D の 2 段 4 コマ＋引き）:

```
┌────────────┬────────────┐
│     2      │     1      │  1 二人の位置関係（引き）/ 2 A
├────────────┼────────────┤
│     4      │     3      │  3 B / 4 A（反応）
├────────────┴────────────┤
│            5            │  引きに戻す（関係の変化）
└─────────────────────────┘
```

- ショット: 1 `medium` か `full`（二人とも入る、`over_shoulder` も可）→ 2 `bust`（`subject`）→ 3 `bust`（`subject`）→ 4 `closeup`（`moment`）→ 5 `long` / `high`（`aspect`）
- なぜ効くか: 最初に位置関係を見せておけば、切り返しの寄りでも誰がどこにいるか迷わない。寄りが 4 コマ以上続くと位置関係が消え、目が滑る（P05）。5 で引きに戻すと、関係が変わった瞬間（距離が縮む、背を向ける）を絵で見せられる。
- 想定線（イマジナリーライン）を守る: 2 人の会話ではカメラを想定線の片側に置き、右にいる人物のセリフは右、左の人物は左（かかし朝浩、https://posfie.com/@natamamenoki/p/umXkNYo ）。線を越えるなら、手前と奥の関係を保つか、越える瞬間を 1 コマ見せる。
- 文字・漫符・効果: 先に話す人物を右に置く（吹き出しの順と視線がそろう。`name_lint.py` の B06）。1 コマの吹き出しは 2 つまで（目安、https://blog.copainter.ai/manga-fukidashi-guide/ ）。吹き出しが交差するなら、絵の側で人物の左右を入れ替える（https://shincomi.shogakukan.co.jp/training/006.html ）。
- よくある失敗: 全コマ `bust` で背景が白（P04・P05）。双方が知っていることを読者のために言わせる。会話の中身が変わったのに構図が変わらない。
- 骨格:

```toml
tiers = [0.33, 0.33, 0.34]
panels = [
  {tier = 0, width = 0.5, shot = "medium", angle = "over_shoulder", background = "detailed", beat = "二人の位置"},
  {tier = 0, width = 0.5, shot = "bust", transition = "subject"},
  {tier = 1, width = 0.5, shot = "bust", transition = "subject"},
  {tier = 1, width = 0.5, shot = "closeup", transition = "moment"},
  {tier = 2, shot = "long", angle = "high", transition = "aspect"},
]
```

## 05 群像・会議（三人以上）

- こういうとき: 3 人以上が同じ場で話す。会議、作戦会議、食卓、教室。
- 形: 最初に俯瞰の引きで全員の配置を見せ、話者ごとに寄る。話題が変わるたびに引きへ戻る。

```
┌─────────────────────────┐
│            1            │  俯瞰で全員の配置（席順）
├────────┬────────┬───────┤
│   4    │   3    │   2   │  発言者の寄り（席順と左右をそろえる）
├────────┴────────┴───────┤
│            5            │  全体の反応（引き）
└─────────────────────────┘
```

- ショット: 1 `long` / `high` か `bird` → 2〜4 `bust`（`subject`）→ 5 `medium` か `long`（`aspect`）
- なぜ効くか: 席順を一度見せておけば、寄りのコマで人物の向きと左右から誰に話しているかが分かる。対決の場面なら、俯瞰の大ゴマのあとに表情のアップを置く（https://www.clipstudio.net/oekaki/archives/151761 ）。
- 文字・漫符・効果: 黙っている人物の反応（`manpu` の `sweat_drops`、`gloom_lines`）を 5 に集める。発言のない寄りは作らない。
- よくある失敗: 全員に毎回台詞を言わせる。寄りの向きが席順と逆になる。誰の台詞か分からない（B09）。
- 骨格:

```toml
tiers = [0.35, 0.35, 0.3]
panels = [
  {tier = 0, shot = "long", angle = "bird", scene = "s2", place = "会議室", background = "detailed"},
  {tier = 1, width = 0.34, shot = "bust", transition = "subject"},
  {tier = 1, width = 0.33, shot = "bust", transition = "subject"},
  {tier = 1, width = 0.33, shot = "bust", transition = "subject"},
  {tier = 2, shot = "medium", transition = "aspect"},
]
```

## 06 沈黙・間

- こういうとき: 返事の前、言えない一言、気まずさ、余韻。台詞を言わせると軽くなる瞬間。
- 形（同構図の反復）:

```
┌────────┬────────┬───────┐
│   3    │   2    │   1   │  同じ構図で、少しだけ違う 3 コマ
├────────┴────────┴───────┤
│            4            │  横長の無言（情景・二人の距離）
└─────────────────────────┘
```

- ショット: 1〜3 同じ `shot`・`angle`（`moment`）→ 4 `long`（`aspect`）
- なぜ効くか: 動かない絵の反復は、読者に「時間が経っている」と読ませる。変わるのは一点（視線が落ちる、指が動く、湯気が消える）だけにすると、その一点が感情になる。横長の無言コマは長い時間として読まれる（`paneling.md` 3 節・8 節）。
- 文字・漫符・効果: 1〜3 は無言か「……」1 つ。4 に台詞を置かない。漫符は控える（`sweat_drops` 1 つまで）。
- よくある失敗: 反復のコマごとに台詞を入れて間を潰す。意図した反復なのに P04 を「直して」しまう（keep の理由を残す）。
- 骨格:

```toml
tiers = [0.35, 0.65]
panels = [
  {tier = 0, width = 0.34, shot = "bust", angle = "profile", beat = "向かい合う"},
  {tier = 0, width = 0.33, shot = "bust", angle = "profile", transition = "moment", beat = "視線が落ちる"},
  {tier = 0, width = 0.33, shot = "bust", angle = "profile", transition = "moment", beat = "指が動く"},
  {tier = 1, shot = "long", transition = "aspect", beat = "夕焼けの土手、二人の間の距離"},
]
```

## 07 リアクション・驚き（小コマ連打 → 大ゴマ）

- こういうとき: 驚き、ショック、衝撃の事実を聞いた直後。
- 形（型 B）:

```
┌────────┬────────┬───────┐
│   3    │   2    │   1   │  手が止まる / 目が見開く / 息をのむ
├────────┴────────┴───────┤
│                         │
│            4            │  全身か顔の大ゴマ（反応の頂点）
│                         │
└─────────────────────────┘
```

- ショット: 1 `insert`（手元、`action`）→ 2 `extreme_closeup`（目、`subject`）→ 3 `closeup`（`moment`）→ 4 `full` か `closeup` / `dutch` か `high`（`moment`）
- なぜ効くか: 小ゴマで時間を細かく刻むと、反応までの一瞬が引き延ばされる。大ゴマとの落差で驚きが大きく見える。
- 文字・漫符・効果: 1 に `sfx`（「ピタッ」）、2 に `surprise_mark`、4 に `beta_flash` か `uni_flash`、または `shock_spikes`。叫びの吹き出しは 4 の 1 つだけ（叫びは 1 ページ 1〜2 個まで、目安 https://blog.copainter.ai/manga-fukidashi-guide/ 、B11）。
- よくある失敗: 毎回の驚きをこの型にする（小さな驚きは 1 コマの `surprise_mark` で足りる）。1〜3 すべてに台詞を入れる。
- 骨格:

```toml
tiers = [0.28, 0.72]
panels = [
  {tier = 0, width = 0.34, shot = "insert", transition = "action", beat = "手が止まる"},
  {tier = 0, width = 0.33, shot = "extreme_closeup", transition = "subject", beat = "目"},
  {tier = 0, width = 0.33, shot = "closeup", transition = "moment"},
  {tier = 1, shot = "full", angle = "dutch", transition = "moment", effects = ["beta_flash"]},
]
```

## 08 告白・決め台詞（溜め → 大ゴマ）

- こういうとき: 告白、宣言、決意、作品の決め台詞。言う前の時間が読みどころになる場面。
- 形: 前のページを均等で静かな割りにして、左ページの最後で言いかけ、めくった右ページの 1 コマ目の大ゴマで言う。

```
     左ページ（引き）                    右ページ（見せ）
┌────────────┬────────────┐      ┌─────────────────────────┐
│     2      │     1      │      │                         │
├────────────┼────────────┤      │            1            │
│     4      │     3      │      │   決め台詞の大ゴマ        │
├────────────┴────────────┤      ├────────────┬────────────┤
│  5 息を吸う・言いかけ     │      │     3      │     2      │  相手の反応
└─────────────────────────┘      └────────────┴────────────┘
```

- ショット（左）: 1〜4 `medium`・`bust` の均等な往復 → 5 `closeup`（口元、`insert` も可）。（右）1 `closeup` か `bust` / `low`（`moment`）→ 2〜3 相手の `closeup`（`subject`）
- なぜ効くか: めくり直前のページを単調にすると、めくった後の大ゴマの落差が大きくなる（大今良時、https://www.clipstudio.net/oekaki/archives/152311 ）。言いかけで止めると、読者は答えを見る前にめくる。
- 文字・漫符・効果: 左 5 は「あのさ」程度か無言。右 1 の台詞は 1〜2 行。長いなら吹き出しを 2 つに割り、後ろを下にずらす（https://mannavi.net/19591/ ）。漫符は `heavy_blush` を言う側か受ける側の一方に。`flower_background` や `sparkles` は約束がラブコメのときだけ。
- よくある失敗: 告白の台詞と相手の返事が同じ見開きにある（答えが先に目に入る）。言う前の時間を 1 コマで済ませる。大ゴマの横に説明のモノローグを並べる（見せ場の絵の横に台詞をまとめない、https://mannavi.net/19591/ ）。
- 骨格（左ページ）:

```toml
turn = "言いかけて止まる → めくって大ゴマで告白"
tiers = [0.3, 0.3, 0.4]
panels = [
  {tier = 0, width = 0.5, shot = "medium"}, {tier = 0, width = 0.5, shot = "medium", transition = "subject"},
  {tier = 1, width = 0.5, shot = "bust", transition = "subject"}, {tier = 1, width = 0.5, shot = "bust", transition = "subject"},
  {tier = 2, shot = "closeup", transition = "moment", beat = "息を吸う"},
]
```

## 09 涙・感情の決壊

- こういうとき: こらえていた感情があふれる。泣く、怒りが爆発する、笑い崩れる。
- 形: こらえる小ゴマ → 決壊の大ゴマ（タチキリ）→ 余韻の横長。

```
┌────────┬────────────────┐
│   2    │       1        │  1 こらえる（唇・握った手）/ 2 目に涙がたまる
├────────┴────────────────┤
│                         │
│            3            │  決壊（タチキリ、顔か全身）
│                         │
├─────────────────────────┤
│            4            │  余韻（背中・情景・相手の手）
└─────────────────────────┘
```

- ショット: 1 `insert`（握った手、`action`）→ 2 `extreme_closeup`（目、`moment`）→ 3 `closeup` か `full` / `high`（`moment`）→ 4 `long` か `back`（`aspect`）
- なぜ効くか: こらえる時間を先に見せるから、決壊が「ずっと我慢していたもの」として読まれる。決壊の直後に引くと、感情の大きさを周りの静けさで受けられる。
- 文字・漫符・効果: 3 の台詞は短い一言か無言。`tears` を 3 に。泣き声の `sfx` は小さく。4 に台詞を置かない。
- よくある失敗: 決壊のコマにモノローグで理由を説明する（理由は前のページで渡しておく）。`tears` を前後のコマにも並べて記号が薄まる（M03）。
- 骨格:

```toml
tiers = [0.25, 0.5, 0.25]
panels = [
  {tier = 0, width = 0.65, shot = "insert", transition = "action", beat = "握りしめた手"},
  {tier = 0, width = 0.35, shot = "extreme_closeup", transition = "moment", beat = "目に涙"},
  {tier = 1, shot = "closeup", angle = "high", transition = "moment", bleed = "right"},  # 右ページの例。外側（小口）の辺だけを紙の端へ
  {tier = 2, shot = "long", angle = "back", transition = "aspect"},
]
```

`bleed` の辺は、そのページのノドにかからないものを選ぶ（P12）。

## 10 回想への入り

- こういうとき: 過去の出来事を場面として見せる。
- 形: 現在の物の寄り（インサート）→ 同じ物の過去の姿 → 過去の場面の引き。

```
┌────────────┬────────────┐
│     2      │     1      │  1 現在: 古い写真・傷・形見 / 2 同じ物の過去（枠を変える）
├────────────┴────────────┤
│            3            │  過去の場面の引き（ナレーションで時を一度だけ）
└─────────────────────────┘
```

- ショット: 1 `insert`（現在、`subject`）→ 2 `insert`（過去、`scene`）→ 3 `long`（過去の場所、`scene`）
- なぜ効くか: 同じ物を二つの時間で並べると、読者は物を橋にして時間を渡れる。説明のナレーションが要らない。
- 回想の印: 枠線を変える（二重線、角を丸める、枠なし）、背景のトーンを変える、コマの外を黒く塗る。回想の吹き出しは二重線にする目安もある（https://blog.copainter.ai/manga-fukidashi-guide/ ）。作品の中で印を一つに決め、演出シートに書く。TOML ではページかコマに `note = "回想: 枠線を二重に"` を残す（配置計算は線を描かない）。
- 文字・漫符・効果: 3 に `narration` で時と場所を一度だけ（「十年前」）。
- よくある失敗: 回想の頭で、いつの何の話かを長いナレーションで説明する。回想と現在の印が混ざり、どこで戻ったか分からない。
- 骨格:

```toml
tiers = [0.4, 0.6]
panels = [
  {tier = 0, width = 0.5, shot = "insert", transition = "subject", beat = "今の手の中の古い鍵"},
  {tier = 0, width = 0.5, shot = "insert", transition = "scene", scene = "s_past", place = "祖母の家の玄関", beat = "新しい鍵"},
  {tier = 1, shot = "long", transition = "scene", beat = "十年前の夏の玄関"},
]
```

## 11 回想からの戻り

- こういうとき: 回想を閉じて現在に戻る。
- 形: 回想の最後の一コマ（感情の核）→ 現在の同じ人物の同じ構図 → 現在の引き。

```
┌────────────┬────────────┐
│     2      │     1      │  1 過去の顔（回想の印つき）/ 2 現在の顔（同じ構図）
├────────────┴────────────┤
│            3            │  現在の場面の引き
└─────────────────────────┘
```

- ショット: 1 `closeup`（過去）→ 2 `closeup`（現在、同じ `angle`、`scene`）→ 3 `medium` か `long`（`aspect`）
- なぜ効くか: 同じ構図で過去と現在を並べると、その間に流れた時間と、変わったもの（傷、表情）が一目で分かる。
- よくある失敗: 戻った最初のコマで回想の意味をモノローグでまとめる。戻りの合図が無く、読者が回想の続きだと思う。
- 骨格:

```toml
tiers = [0.45, 0.55]
panels = [
  {tier = 0, width = 0.5, shot = "closeup", scene = "s_past", beat = "幼い顔"},
  {tier = 0, width = 0.5, shot = "closeup", transition = "scene", scene = "s3", place = "病室", beat = "今の顔"},
  {tier = 1, shot = "long", transition = "aspect"},
]
```

## 12 場面転換・エスタブリッシュ

- こういうとき: 場所や時間が変わる。新しい場所に入る。
- 形: 外観の引き（1 コマ、横長）→ 中の引き → 人物。

```
┌─────────────────────────┐
│            1            │  外観・遠景（建物、街、空）
├─────────────────────────┤
│            2            │  中の様子（人物の位置）
├────────────┬────────────┤
│     4      │     3      │  人物の寄り
└────────────┴────────────┘
```

- ショット: 1 `extreme_long`（`scene`）→ 2 `long`（`subject`）→ 3・4 `medium`・`bust`
- なぜ効くか: 背景で「いつ・どこで」が伝わる（https://shincomi.shogakukan.co.jp/training/007.html ）。冒頭と、場所・時間が変わるときは背景を描く（https://manga-biz.com/column/webtoon_2/ 、目安）。
- 文字・漫符・効果: 1 に看板・表札の `sign`（場所を文字で示すなら台詞より看板）。ナレーションは「翌朝」程度。
- よくある失敗: 場面の頭が顔の寄りで、どこか分からない（P03・P11）。毎場面の頭を外観にして単調になる（日常の連続した場面は 2 から始めてよい）。
- 骨格:

```toml
tiers = [0.25, 0.4, 0.35]
panels = [
  {tier = 0, shot = "extreme_long", transition = "scene", scene = "s4", place = "商店街の喫茶店", time = "雨の夕方"},
  {tier = 1, shot = "long", transition = "subject"},
  {tier = 2, width = 0.5, shot = "medium"}, {tier = 2, width = 0.5, shot = "bust", transition = "subject"},
]
```

## 13 時間経過（同じ場所の定点）

- こういうとき: 待つ、季節が移る、作業が続く、関係がゆっくり変わる。
- 形: 同じ構図・同じ場所で、光・物・人物の位置だけが変わる 3〜4 コマ。

```
┌─────────────────────────┐
│            1            │  朝: 机に向かう
├─────────────────────────┤
│            2            │  昼: 紙が積もる
├─────────────────────────┤
│            3            │  夜: 窓が暗い、突っ伏す
└─────────────────────────┘
```

- ショット: 1〜3 同じ `shot`・`angle`（`aspect` か `scene`）
- なぜ効くか: 変わらない構図の中で変わったものが、経過した時間そのものになる。時計やカレンダーを映すより自然。
- 文字・漫符・効果: 台詞なし。経過の量を示すなら `sign`（時計）か、各コマにごく短いナレーション（「三日目」）。
- よくある失敗: 毎コマ構図を変えて定点の効果が消える。P04（同じショットの連続）を直してしまう（意図した定点は keep）。
- 骨格:

```toml
tiers = [1, 1, 1]
panels = [
  {tier = 0, shot = "long", angle = "high", beat = "朝"},
  {tier = 1, shot = "long", angle = "high", transition = "aspect", beat = "昼"},
  {tier = 2, shot = "long", angle = "high", transition = "aspect", beat = "夜"},
]
```

## 14 打撃アクション（予備動作 → インパクト → 結果）

- こういうとき: 殴る、蹴る、斬る、投げる。一撃を確実に見せたい。
- 形:

```
┌────────────┬────────────┐
│     2      │     1      │  1 予備動作（構え・振りかぶり）/ 2 踏み込み
├────────────┴────────────┤
│                         │
│            3            │  インパクト（大ゴマ、斜めか変形も可）
│                         │
├─────────────────────────┤
│            4            │  結果（吹き飛ぶ相手・残心）
└─────────────────────────┘
```

- ショット: 1 `medium`（`action`）→ 2 `full` / `low`（`action`）→ 3 `medium` か `full` / `dutch`（`action`）→ 4 `long`（`action`）
- なぜ効くか: 予備動作で力の向きを見せておくと、インパクトの一コマで何が起きたかが読める。結果のコマで威力が分かる。
- 文字・漫符・効果: 1 に `motion_arc`、2 に `speed_lines`、3 に `impact_burst` と大きな `sfx`（白フチの描き文字）、4 に `afterimage` や土煙。3 に台詞を置かない（絵が先に目に入るように）。
- 想定線: 攻撃の向き（右から左など）を 1〜4 で変えない。向きが変わると、誰が攻めているか分からなくなる。
- よくある失敗: インパクトだけの 1 コマで、何が当たったか分からない。全コマに `focus_lines` を敷いて、どこが山か消える。変形ゴマを毎ページ使う（「ここぞ」に限る、https://shincomi.shogakukan.co.jp/training/005.html ）。
- 骨格:

```toml
tiers = [0.25, 0.5, 0.25]
panels = [
  {tier = 0, width = 0.5, shot = "medium", transition = "action", effects = ["motion_arc"]},
  {tier = 0, width = 0.5, shot = "full", angle = "low", transition = "action", effects = ["speed_lines"]},
  {tier = 1, shot = "full", angle = "dutch", transition = "action", effects = ["impact_burst"]},
  {tier = 2, shot = "long", transition = "action", effects = ["afterimage"]},
]
```

## 15 攻防の応酬

- こういうとき: 打ち合い、剣戟、言葉の応酬が続く。
- 形: 同じ大きさの小ゴマを交互に（A の攻撃 / B の受け）並べ、最後の一合だけ大きく。

```
┌────────┬────────┬───────┐
│   3    │   2    │   1   │  A 攻 / B 受 / A 攻
├────────┼────────┼───────┤
│   6    │   5    │   4   │  B 返し / A 受 / B 攻
├────────┴────────┴───────┤
│            7            │  決着の一合（大）
└─────────────────────────┘
```

- ショット: 1〜6 `medium`・`bust` を交互に（`action`）、angle も交互に `low` / `high` → 7 `full` / `dutch`
- なぜ効くか: 同じ大きさの小ゴマは等しいテンポを刻み、読者の目を速く走らせる。最後だけ大きくするとテンポが止まり、決着が際立つ。7 コマはこの型の中だけの例外で、通常は 8 コマを上限にする（https://www.clipstudio.net/oekaki/archives/149462 ）。
- 文字・漫符・効果: 小ゴマは台詞なしか一語。`sfx` を各コマに（金属音、打撃音）。効果線は小ゴマで細く、7 で太く。
- よくある失敗: 小ゴマに長い台詞を入れてテンポが止まる。誰がどちらにいるかが入れ替わる。
- 骨格:

```toml
tiers = [0.3, 0.3, 0.4]
panels = [
  {tier = 0, width = 1, shot = "medium", angle = "low"}, {tier = 0, width = 1, shot = "medium", angle = "high", transition = "action"},
  {tier = 0, width = 1, shot = "bust", angle = "low", transition = "action"},
  {tier = 1, width = 1, shot = "medium", angle = "high", transition = "action"}, {tier = 1, width = 1, shot = "bust", angle = "low", transition = "action"},
  {tier = 1, width = 1, shot = "medium", angle = "high", transition = "action"},
  {tier = 2, shot = "full", angle = "dutch", transition = "action", effects = ["impact_burst"]},
]
```

## 16 追跡・移動

- こういうとき: 走る、追う、逃げる、乗り物で移動する。
- 形: 横長のコマを縦に重ねる（横の移動は横長で）。最後に距離を見せる俯瞰。

```
┌─────────────────────────┐
│            1            │  逃げる側（左へ走る）
├─────────────────────────┤
│            2            │  追う側（同じく左へ）
├────────────┬────────────┤
│     4      │     3      │  足・手のインサート / 振り返る顔
├────────────┴────────────┤
│            5            │  俯瞰で二人の距離
└─────────────────────────┘
```

- ショット: 1 `full` / `profile`（`action`）→ 2 `full` / `profile`（`subject`）→ 3 `closeup`（`subject`）→ 4 `insert`（`action`）→ 5 `long` / `bird`（`aspect`）
- なぜ効くか: 横長のコマは横の移動と時間の流れに向く。進む向きをそろえると、読者は追う・追われるを迷わない。日本の漫画は右から左へ読むので、左へ進む動きは「前へ進む」、右へ戻る動きは「押し返される・逃げ戻る」と読まれやすい（目安）。
- 文字・漫符・効果: `speed_lines` を背景に。追う側の息（`steam_breath`）、逃げる側の汗（`droplets_splash`）。
- よくある失敗: コマごとに走る向きが変わる。距離の変化が見えない（5 が無い）。
- 骨格:

```toml
tiers = [0.22, 0.22, 0.28, 0.28]
panels = [
  {tier = 0, shot = "full", angle = "profile", effects = ["speed_lines"]},
  {tier = 1, shot = "full", angle = "profile", transition = "subject", effects = ["speed_lines"]},
  {tier = 2, width = 0.5, shot = "closeup", transition = "subject"}, {tier = 2, width = 0.5, shot = "insert", transition = "action"},
  {tier = 3, shot = "long", angle = "bird", transition = "aspect"},
]
```

## 17 必殺技・変身・覚醒

- こういうとき: 作品のクライマックス、技の発動、力の解放。
- 形: 前のページで溜め（目のアップ、構え、周りの反応）→ めくって見開きか 1 ページ大ゴマ（タチキリ）→ 次のページで結果。

```
 左ページ: 溜め（小ゴマで刻む）  →  めくり  →  見開き（spread = true を右ページに）
```

- ショット: 溜め `extreme_closeup`・`insert`（`moment`）→ 見開き `full` か `extreme_long` / `low` か `worm`（`action`）
- なぜ効くか: 見開きはクライマックスで使う（https://shincomi.shogakukan.co.jp/training/005.html ）。印象的な構図は扉とクライマックスを含めて 5〜7 箇所に絞り、それ以外は平凡でよい（MANZEMI、https://manzemi.net/lesson/2576 、目安）。絞るから、ここが効く。
- 文字・漫符・効果: 見開きは `white_flash` か `beta_flash`、`status_sigil`（魔法陣・光輪）。技名は描き文字で大きく 1 つ。説明台詞は見開きに置かず、後のページで周りに言わせる。
- よくある失敗: 毎話見開きを使う。見開きが左ページから始まる（P08）。ノド（綴じ目）に顔や台詞が来る。
- 骨格（見開きの右ページ）:

```toml
spread = true
splash = true
tiers = [1.0]
panels = [{tier = 0, shot = "full", angle = "worm", bleed = true, effects = ["white_flash"]}]
```

## 18 恐怖の接近

- こういうとき: ホラー、サスペンス。何かが近づく、何かがいる気配。
- 形: 同じ構図でズームインを重ね（対象が少しずつ近い・大きい）、左ページの最後で振り向く直前で止め、めくって正体。

```
     左ページ                               右ページ（めくり後）
┌─────────────────────────┐        ┌─────────────────────────┐
│            1            │ 廊下の奥 │                         │
├─────────────────────────┤        │            1            │
│            2            │ 少し近い │   正体（大ゴマ、黒地）     │
├────────────┬────────────┤        │                         │
│     4      │     3      │        ├─────────────────────────┤
│  振り向く  │   首筋の汗  │        │            2  反応       │
└────────────┴────────────┘        └─────────────────────────┘
```

- ショット: 1 `long` / `pov`（`aspect`）→ 2 `long` / `pov`（`moment`、対象だけ近い）→ 3 `extreme_closeup`（`subject`）→ 4 `bust` / `back`（`action`）→ めくって 1 `closeup` か `full` / `low`（`moment`）
- なぜ効くか: 同じ構図の反復で対象だけが動くと、読者は「近づいている」ことに自分で気づく。正体を見開きの中に置かず、めくりの先に隠す（`paneling.md` 5 節）。
- 文字・漫符・効果: 台詞は少なく。`sfx` は小さく（「ひた」「ぎし」）。`trembling_lines`、`sweat_drops`。正体のコマは `beta_flash` か `black_background`。怖さの頂点では漫符を消す（記号は笑いに寄る）。
- よくある失敗: 正体と反応が同じ見開き。説明台詞で怖さを言う（「なんて恐ろしい」）。
- 骨格（左ページ）:

```toml
turn = "振り向く直前で止める → めくって正体"
tiers = [0.3, 0.3, 0.4]
panels = [
  {tier = 0, shot = "long", angle = "pov", transition = "aspect"},
  {tier = 1, shot = "long", angle = "pov", transition = "moment"},
  {tier = 2, width = 0.5, shot = "extreme_closeup", transition = "subject"},
  {tier = 2, width = 0.5, shot = "bust", angle = "back", transition = "action"},
]
```

## 19 種明かし・推理

- こういうとき: 謎解き、手がかりの回収、真相の説明。
- 形: 推理する人物の寄りと、手がかりのインサート（前に出た物を同じ構図で再掲）を交互に。最後に犯人・真相の大ゴマ。

```
┌────────────┬────────────┐
│     2      │     1      │  1 探偵の台詞 / 2 手がかり A（前に出た絵の再掲）
├────────────┼────────────┤
│     4      │     3      │  3 探偵 / 4 手がかり B
├────────────┴────────────┤
│            5            │  真相・犯人の反応（大）
└─────────────────────────┘
```

- ショット: 1 `bust` → 2 `insert`（`subject`）→ 3 `bust` → 4 `insert` → 5 `closeup` / `low`（`moment`）
- なぜ効くか: 長い説明台詞を、絵の再掲で分割できる。読者は「あのコマだ」と前を思い出し、自分で謎が解けた気分になる。手がかりのインサートは、最初に出したときと同じ `shot`・`angle` にする。
- 文字・漫符・効果: 推理の台詞は 1 吹き出し 1 論点。長くなるなら吹き出しを割る（B01）。手がかりのコマに台詞を重ねない。
- よくある失敗: 手がかりが本編で一度も描かれていない（後出し）。台詞だけのコマが続く（P05）。
- 骨格:

```toml
tiers = [0.3, 0.3, 0.4]
panels = [
  {tier = 0, width = 0.5, shot = "bust"}, {tier = 0, width = 0.5, shot = "insert", transition = "subject", beat = "P3-2 と同じ割れた時計"},
  {tier = 1, width = 0.5, shot = "bust", transition = "subject"}, {tier = 1, width = 0.5, shot = "insert", transition = "subject"},
  {tier = 2, shot = "closeup", angle = "low", transition = "moment"},
]
```

## 20 ひらめき・気づき

- こういうとき: 人物が何かに気づく。解決策を思いつく。
- 形: 何気ない物 → 物の寄り → 目が見開く（2 コマ連続の `moment`）。

```
┌────────────┬────────────┐
│     2      │     1      │  1 何気ない動作 / 2 物の寄り
├────────────┴────────────┤
│            3            │  目のアップ（気づき）→ 次のコマで行動
└─────────────────────────┘
```

- ショット: 1 `medium` → 2 `insert`（`subject`）→ 3 `extreme_closeup`（`moment`）
- 文字・漫符・効果: 3 に `lightbulb` か `uni_flash`、または `surprise_mark`。気づき線（顔の周りの短い放射線、https://ja.wikipedia.org/wiki/漫符 ）はネームのキーが無いので、`lightbulb` か `shock_spikes` で代える（`emotion_mark` は Krea の kind の名前で、ネームの `manpu` には書けない）。「そうか！」の台詞は 1 つまで。
- よくある失敗: 気づいた内容をすぐ台詞で全部説明する（行動で見せる）。
- 骨格:

```toml
tiers = [0.45, 0.55]
panels = [
  {tier = 0, width = 0.5, shot = "medium"}, {tier = 0, width = 0.5, shot = "insert", transition = "subject"},
  {tier = 1, shot = "extreme_closeup", transition = "moment"},
]
```

## 21 ギャグのボケ → ツッコミ

- こういうとき: 掛け合いの笑い。
- 形: フリ（普通の状況）→ ボケ（大まじめ）→ 間（1 コマ、無言の真顔）→ ツッコミ（大きく）。

```
┌────────────┬────────────┐
│     2      │     1      │  1 フリ / 2 ボケ（真顔で）
├────────────┴────────────┤
│            3            │  間（無言、相手の顔）
├─────────────────────────┤
│            4            │  ツッコミ（大、叫び）
└─────────────────────────┘
```

- ショット: 1 `medium` → 2 `bust`（真顔、`subject`）→ 3 `bust`（相手、無言、`subject`）→ 4 `full` / `dutch`（`action`）
- なぜ効くか: ボケの直後に無言のコマを置くと、読者がボケを理解する時間ができ、ツッコミで笑いが確定する。ボケた本人が大まじめなほど、周りとの温度差が笑いになる。
- 文字・漫符・効果: 2 は漫符なし（真顔が効く）。3 に `sweat_drops` か `gloom_lines`。4 は `shout` の吹き出しと `anger_vein`、`impact_burst`。
- よくある失敗: ボケのコマに `sweat_drops` や「ボケ」の記号を付けて、本人がふざけていると見せる。間のコマを省く。ツッコミで状況を説明する（説明すると笑いが冷える）。
- 骨格:

```toml
tiers = [0.3, 0.3, 0.4]
panels = [
  {tier = 0, width = 0.5, shot = "medium"}, {tier = 0, width = 0.5, shot = "bust", transition = "subject", beat = "真顔のボケ"},
  {tier = 1, shot = "bust", transition = "subject", beat = "無言の相手"},
  {tier = 2, shot = "full", angle = "dutch", transition = "action", effects = ["impact_burst"]},
]
```

## 22 天丼（繰り返しのギャグ）

- こういうとき: 同じボケを 2 回、3 回と重ねて笑いを大きくする。
- 形: 1 回目と 2 回目は**同じ構図・同じコマの形**で再現し、3 回目だけ構図か大きさを裏切る。
- ショット: 1 回目と 2 回目は同じ `shot`・`angle`。3 回目は寄りか引きに変える（`non_sequitur` も可）。
- なぜ効くか: 同じ形の再現で、読者は「また来た」と予期する。予期が育ったところで外すか、もっと大きくやる。
- 文字・漫符・効果: 台詞も同じ文面で繰り返す（言い換えると天丼に見えない）。3 回目にだけ漫符を足す。
- よくある失敗: 毎回構図が違って、繰り返しに気づかれない。4 回以上同じ大きさで続けて飽きる。
- 骨格: 1 回目のコマの TOML をそのまま写し、`beat` と変化させる一点だけを書き換える。

## 23 オチ（大きく落とす）

- こういうとき: ギャグ回や短編の最後。最大の笑い、どんでん返し。
- 形: 直前を小ゴマで刻んで、最後のコマを横幅いっぱいの大ゴマにする。

```
┌────────┬────────┬───────┐
│   3    │   2    │   1   │  小ゴマで畳みかける
├────────┴────────┴───────┤
│                         │
│            4            │  オチ（大、引きで全体）
│                         │
└─────────────────────────┘
```

- ショット: 1〜3 `bust`・`closeup` → 4 `long` か `extreme_long` / `high`（`aspect` か `non_sequitur`）
- なぜ効くか: 寄りから一気に引くと、状況の全体（何が起きていたか）が一目で分かり、それが落ちになる。
- 文字・漫符・効果: 4 は台詞なしか一言。説明は書かない（オチのあとに温かいまとめを足すとオチが弱る）。
- よくある失敗: オチのコマに説明の台詞やナレーションを置く。オチを左ページの最初のコマ（同じ見開きの中で先に見える位置）に置く。
- 骨格:

```toml
tiers = [0.3, 0.7]
panels = [
  {tier = 0, width = 1, shot = "bust"}, {tier = 0, width = 1, shot = "closeup", transition = "moment"},
  {tier = 0, width = 1, shot = "closeup", transition = "moment"},
  {tier = 1, shot = "extreme_long", angle = "high", transition = "non_sequitur"},
]
```

## 24 オチ（小さく突き放す）

- こういうとき: シュールな笑い、苦い結末、余韻で落とす。
- 形: 最後のコマを小さく、端に置く。大きな空白か情景のコマのあとに、ぽつんと一コマ。

```
┌─────────────────────────┐
│            1            │  情景（横長・無言）
├─────────────────┬───────┤
│     （空白）     │   2   │  小さな最後の一コマ（右）
└─────────────────┴───────┘
```

- ショット: 1 `long`（`aspect`）→ 2 `insert` か `bust`（`non_sequitur`）
- なぜ効くか: 小さいコマは読者を突き放す。大きく盛り上げないことで、乾いた笑いや苦さが残る。
- 文字・漫符・効果: 2 に一言か、欄外の小文字（`type = "aside"`）。漫符は使わない。
- よくある失敗: 空白に意味を説明する文字を入れる。
- 骨格: 2 段目の右に `width = 0.3` の小コマ 1 つだけを置き、左を空ける場合は `bbox` で位置を決める（`tier` だけだと段の幅いっぱいに広がる）。

## 25 対比（ビフォーアフター）

- こういうとき: 変化を見せる。昔と今、期待と現実、変身の前後。
- 形: 同じ構図・同じ大きさのコマを 2 つ並べる（右が前、左が後）。

```
┌────────────┬────────────┐
│     2      │     1      │  1 前 / 2 後（同じ構図）
│   (後)     │   (前)     │
└────────────┴────────────┘
```

- ショット: 1 と 2 は同じ `shot`・`angle`。`transition = "scene"`（時間が飛ぶ）か `moment`
- なぜ効くか: 構図を固定すると、違いだけが目に入る。読む順（右→左）が時間の順になる。
- 文字・漫符・効果: 違いを台詞で説明しない。必要なら各コマに短いラベル（「入学式」「卒業式」）を `narration` で。
- よくある失敗: 構図が違って比較にならない。前と後を逆の順に置く。
- 骨格:

```toml
tiers = [1.0]
panels = [
  {tier = 0, width = 0.5, shot = "full", angle = "eye", beat = "前"},
  {tier = 0, width = 0.5, shot = "full", angle = "eye", transition = "scene", beat = "後"},
]
```

## 26 左右対比（二人の対照）

- こういうとき: 対立する二人、同じ瞬間の二人の違う反応、鏡像の関係。
- 形: 縦長のコマを左右に並べ、二人を鏡のように置く（右の人物は左向き、左の人物は右向き）。

```
┌────────────┬────────────┐
│            │            │
│     2      │     1      │  向かい合う構図・同じ大きさ
│   （B）    │   （A）    │
└────────────┴────────────┘
```

- ショット: 1 と 2 は同じ `shot`、`angle` は `profile` か鏡像の `low` / `high`（強弱を見せるなら A を `low`、B を `high`）
- なぜ効くか: 同じ大きさで並べると、二人が対等に見える。片方を煽り、片方を俯瞰にすると力関係が出る。
- 文字・漫符・効果: 台詞も左右対称に（同じ長さ、同じ吹き出しの形）。違いは一点だけ（片方だけ `sweat_drops`）。
- よくある失敗: 二人の向きが同じで、対面に見えない。想定線を越えて左右が入れ替わる。
- 骨格:

```toml
tiers = [1.0]
panels = [
  {tier = 0, width = 0.5, shot = "bust", angle = "profile", beat = "A"},
  {tier = 0, width = 0.5, shot = "bust", angle = "profile", transition = "subject", beat = "B（鏡像）"},
]
```

## 27 食事・日常のゆるさ

- こういうとき: 事件の起きない回。食卓、帰り道、休み時間。読者が空気を楽しみに来る。
- 形: 大きめの均等なコマ、引き多め、手元と食べ物のインサート。

```
┌─────────────────────────┐
│            1            │  食卓全体（引き）
├────────────┬────────────┤
│     3      │     2      │  料理のインサート / 箸を伸ばす手
├────────────┴────────────┤
│            4            │  食べた顔（ほころぶ）
└─────────────────────────┘
```

- ショット: 1 `long` / `high` → 2 `insert` → 3 `insert`（`action`）→ 4 `bust`（`moment`）
- なぜ効くか: 引きと手元で「場」を見せると、会話が少なくても空気が伝わる。コマを詰めないことが、ゆるさの速度になる。
- 文字・漫符・効果: `sfx`（湯気、咀嚼音）、`music_notes`、`sparkles`（料理）。台詞は相手への関心で（用件の説明より、好みを尋ねる）。
- よくある失敗: コマを詰めすぎて慌ただしい。料理の説明台詞が長い（B01）。
- 骨格:

```toml
tiers = [0.35, 0.3, 0.35]
panels = [
  {tier = 0, shot = "long", angle = "high", background = "detailed"},
  {tier = 1, width = 0.5, shot = "insert", transition = "subject"}, {tier = 1, width = 0.5, shot = "insert", transition = "action"},
  {tier = 2, shot = "bust", transition = "moment"},
]
```

## 28 別れ・去り際

- こういうとき: 別れ、退場、死別の直後。
- 形: 去る背中が遠ざかる（コマごとに小さく）→ 誰もいない場所のコマ（空のコマ）。

```
┌─────────────────────────┐
│            1            │  背中（ミドル）
├─────────────────────────┤
│            2            │  背中（ロング、小さく）
├─────────────────────────┤
│            3            │  誰もいない場所（同じ構図、人物なし）
└─────────────────────────┘
```

- ショット: 1 `medium` / `back` → 2 `long` / `back`（`moment`）→ 3 `long`（同じ構図、`aspect`）
- なぜ効くか: 遠ざかる背中は距離と時間を、空のコマは不在そのものを見せる。言葉で「寂しい」と言わずに済む。
- 文字・漫符・効果: 残る側の一言は 1 か 2 に 1 つまで。3 は無言（P09 の「空のコマ」は、`beat` に「誰もいない」と書けば出ない）。
- よくある失敗: 3 に「もう二度と会えない」とモノローグを置く。
- 骨格:

```toml
tiers = [0.33, 0.33, 0.34]
panels = [
  {tier = 0, shot = "medium", angle = "back"},
  {tier = 1, shot = "long", angle = "back", transition = "moment"},
  {tier = 2, shot = "long", transition = "aspect", beat = "誰もいない駅のホーム"},
]
```

## 29 スポーツの決定的瞬間

- こういうとき: シュート、ゴール、ホームラン、決勝点。
- 形: 観客と相手の小ゴマ（溜め）→ 決定的瞬間の大ゴマ（時間が止まる）→ 結果の引き。

```
┌────────┬────────┬───────┐
│   3    │   2    │   1   │  観客 / 相手の顔 / 本人の目
├────────┴────────┴───────┤
│                         │
│            4            │  決定的瞬間（タチキリ、止まった時間）
│                         │
├─────────────────────────┤
│            5            │  結果（ボールの行方・歓声）
└─────────────────────────┘
```

- ショット: 1 `extreme_closeup` → 2 `bust`（`subject`）→ 3 `long`（`subject`）→ 4 `full` / `low` か `worm`（`action`）→ 5 `long`（`action`）
- なぜ効くか: 周りの反応を先に刻むと、その一瞬に全員の目が集まっていることが分かる。決定的瞬間は効果線を止めて静止画にすると、時間が止まって見える。
- 文字・漫符・効果: 4 は無音（`sfx` なし）が効く場合がある。5 で大きな `sfx`。
- よくある失敗: 4 で実況台詞を入れる。
- 骨格:

```toml
tiers = [0.25, 0.5, 0.25]
panels = [
  {tier = 0, width = 1, shot = "extreme_closeup"}, {tier = 0, width = 1, shot = "bust", transition = "subject"},
  {tier = 0, width = 1, shot = "long", transition = "subject"},
  {tier = 1, shot = "full", angle = "worm", transition = "action", bleed = "right"},  # 右ページの例。左ページなら "left"
  {tier = 2, shot = "long", transition = "action"},
]
```

## 30 心理戦

- こういうとき: 駆け引き、嘘の見抜き合い、交渉、賭け。
- 形: 目のアップを交互に（同じ大きさ・同じ構図）、間に手元のインサート（カード、グラス、指の動き）。

```
┌────────────┬────────────┐
│     2      │     1      │  1 A の目 / 2 B の目
├────────────┴────────────┤
│            3            │  手元のインサート（嘘の兆候）
├────────────┬────────────┤
│     5      │     4      │  4 A の目（変化）/ 5 B の口元
└────────────┴────────────┘
```

- ショット: 1 `extreme_closeup` → 2 `extreme_closeup`（`subject`）→ 3 `insert`（`subject`）→ 4 `extreme_closeup`（`moment`）→ 5 `closeup`
- なぜ効くか: 目の交互は、言葉の裏の読み合いを絵にする。手元のインサートが、台詞と違う本音を読者だけに見せる。
- 文字・漫符・効果: 心の声（`thought`）で読み合いを書くなら、1 コマ 1 つ、短く。`sweat_sheen`（脂汗）をどちらか一方に。
- よくある失敗: 心の声で全部説明する（読者が推理する余地が消える）。目のアップが続きすぎて、場所と位置関係が消える（途中で引きを 1 つ挟む）。
- 骨格:

```toml
tiers = [0.25, 0.4, 0.35]
panels = [
  {tier = 0, width = 0.5, shot = "extreme_closeup"}, {tier = 0, width = 0.5, shot = "extreme_closeup", transition = "subject"},
  {tier = 1, shot = "insert", transition = "subject"},
  {tier = 2, width = 0.5, shot = "extreme_closeup", transition = "moment"}, {tier = 2, width = 0.5, shot = "closeup", transition = "subject"},
]
```

## 31 4コマの基本（起承転結）

- こういうとき: `format = "yonkoma"` の 1 本。
- 形: 同じ形の 4 コマを縦に（https://comic.smiles55.jp/guide/20130/ ）。

```
┌──────────┐
│    1     │  起: 舞台と人物（誰が、どこで）
├──────────┤
│    2     │  承: 事件が起きて話が進む
├──────────┤
│    3     │  転: 山場。予想をずらす
├──────────┤
│    4     │  結: オチ
└──────────┘
```

- ショット: 1 `full` か `long` → 2 `medium`（`action`）→ 3 `bust` か `closeup`（`moment` か `subject`）→ 4 `long` か `full`（`scene` も可）
- なぜ効くか: 形が同じだから、読者の注意は中身の変化だけに向く。1 で状況を一目で渡しておけば、2〜4 は台詞が少なくて済む。
- 文字・漫符・効果: 1 コマの吹き出しは 1〜2、1 行 10 字が目安（`thresholds.json` の yonkoma）。オチのコマは台詞を最小に。
- よくある失敗: 1 コマ目で状況を台詞で説明する。3 コマ目で落ちてしまう。4 コマ目に「というわけで」の説明。
- 骨格:

```toml
[meta]
format = "yonkoma"
[[pages]]
panels = [
  {role = "起", shot = "full", scene = "s1", place = ""},
  {role = "承", shot = "medium", transition = "action"},
  {role = "転", shot = "bust", transition = "moment"},
  {role = "結", shot = "long", transition = "scene"},
]
```

## 32 4コマ: 3 コマ目のずらし・4 コマ目の無言オチ

- こういうとき: 4コマのオチを強くしたい。
- 3 コマ目のずらし: 3 コマ目で「転」を起こしきらず、答えの手前で止める（固まる、時計を見る、手紙を開く）。オチの中身は 4 コマ目の絵で初めて見せる。
- 4 コマ目の無言オチ: 4 コマ目を台詞なしにし、絵だけで落とす。引きの構図（`long`）で、3 コマ目までと違う場所・状態を見せる（`transition = "scene"` か `non_sequitur`）。補足が要るなら欄外の小文字（`type = "aside"`）を 1 つ。
- 例: `assets/templates/yonkoma.toml`（3 コマ目で時計を見て固まる → 4 コマ目は二度寝の引き）。
- よくある失敗: 3 コマ目の台詞でオチを言ってしまう。4 コマ目で 3 コマ目と同じ構図にして、変化が見えない。

## 33 縦読みの引き（長い余白 → 最後の一コマ）

- こういうとき: `format = "webtoon"` の話の終わり、場面の山。
- 形: 普通の間隔で進めたあと、長い余白（`gap` を大きく）を取り、スクロールの先に最後の一コマ。

```
│ コマ  │
│       │
│ コマ  │   gap 0.15〜0.3（続きの動作）
│       │
│       │
│       │   gap 1.5 以上（溜め）
│       │
│ 引き  │   最後の一コマ（正体・一言・表情）
```

- なぜ効くか: 縦読みは余白が時間（https://www.clipstudio.net/oekaki/archives/156251 ）。長い余白のあいだ、読者は指を動かしながら待つ。紙のめくりの代わりになる。
- 文字・漫符・効果: 最後の一コマの吹き出しは 1 つ、3 行以内（https://info.manga-lab.net/?p=2765 ）。
- よくある失敗: 余白が短く、最後の一コマが前のコマと同じ画面に入ってしまう。最後のコマに次回予告の説明を書く。
- 骨格:

```toml
[[pages]]
panels = [
  {height = 1.0, shot = "medium"},
  {gap = 0.2, height = 0.8, shot = "bust", transition = "moment"},
  {gap = 1.8, height = 1.3, shot = "closeup", transition = "moment", beat = "引き"},
]
```

## 34 縦読みの会話

- こういうとき: 縦読みで二人が話す。
- 形: 横に並べず、上から下へ。1 画面に 1〜3 コマ（https://info.manga-lab.net/?p=2765 ）。吹き出しは上から下へずらし、最後は画面の中央に戻す（https://mannavi.net/21297/ ）。
- ショット: 最初に二人が入る `medium`、そのあとは 1 コマ 1 人の `bust` を縦に。話題の変わり目で `long` を 1 つ。
- よくある失敗: 紙の 4 コマ割り（横並び）を縦読みに持ち込む。1 コマに吹き出しを 3 つ以上積む（webtoon は 1 コマ 2 つまでの目安）。

## 35 成人向けの見せ方（rating = adult）

- こういうとき: 作品の `rating` が `adult` で、性的な場面を描く。**登場人物は全員成人**（`cast.toml` の外見・設定で成人と分かるようにする。幼く見える記述を `appearance` に入れない）。`rating` が `general` の作品にこの節の記号を使うと `name_lint.py` が M04 を出す。
- コマ割りの型（成人向けの単話でよく使われる組み合わせ。目安）:
  - **本編の引き → 寄り**: 位置関係と体勢を引き（`full` か `medium`）で見せ、表情や接触点の寄り（`closeup`・`insert`）へ移る。会話の切り返し（04）と同じく、引きを省くと誰がどこにいるか分からなくなる。
  - **寄りの連打 → 大ゴマ**: 小ゴマで表情と反応を刻み、山場を大ゴマかタチキリで（07・17 と同じ溜めの構造）。
  - **ビフォーアフター**: 同じ構図で前後を並べ、状態の変化を見せる（25）。
  - **左右対比**: 二人の反応、または同じ人物の理性と崩れを左右に並べる（26）。
  - **はめ込み**: 大ゴマの中に表情や手元の小ゴマを `inset = true` で重ね、全体と細部を同時に見せる。
- 記号と効果（`manpu.json` の rating = adult の項目と、一般の項目の転用）: 感情の記号は `sweat_drops`・`sweat_spray`・`heavy_blush`・`floating_hearts`・`dizzy_eyes`・`pulse_marks`、体の効果は `steam_breath`・`trembling_lines`・`pleasure_zigzag`・`skin_shine`・`fluid_strands`、画面の効果は `contact_spikes`・`motion_arc`・`afterimage`・`white_flash`・`mood_gradient`・`hypno_waves`・`status_sigil`。詳しい形・置き場所・意味は `manpu.md` の成人向けの節。
- 擬音: 何の音かで系統を分けて選ぶ（湿った接触、打撃、揺れ、痙攣・心拍、声の記号）。詳しくは `manpu.md`。
- よくある失敗: 引きが一度も無く、体勢が読めない。全コマに同じ記号を敷いて山が消える（M03）。全コマを同じ寄りで続ける（P04・P05）。
- 公開先の規定（年齢確認、AI 表示の区分、修正の要否）は `formats.md` で確かめる。

## 36 最終ページの引き（話を締める）

- こういうとき: 連載の 1 話の最後、読切の最終ページ。
- 形（連載）: 最終ページの最後のコマに「次の問い」を置く。左ページで終わるなら、めくりの先が次話になる。

```
┌─────────────────────────┐
│            1            │  この話の決着（引きで）
├────────────┬────────────┤
│     3      │     2      │  余韻 / 新しい違和感
├────────────┴────────────┤
│            4            │  引き（新しい人物・物・一言）
└─────────────────────────┘
```

- 形（読切）: 決着のあと、主人公の感情が最初と変わったことを 1 コマで見せて終える（1 話の中で主人公の感情が変わるかが最重視、https://www.cmoa.jp/cmoacomics/pickup/post-51-9.html ）。引きを無理に作らない。
- 文字・漫符・効果: 引きのコマは台詞 1 つか無言。「このときはまだ知らなかった」式のナレーションで予告しない（絵の違和感で引く）。
- よくある失敗: 最後のコマで話全体を総括するモノローグ。読切なのに続きを匂わせて決着を曖昧にする。
- 骨格:

```toml
tiers = [0.35, 0.3, 0.35]
panels = [
  {tier = 0, shot = "long"},
  {tier = 1, width = 0.5, shot = "bust", transition = "moment"}, {tier = 1, width = 0.5, shot = "insert", transition = "subject"},
  {tier = 2, shot = "closeup", angle = "low", transition = "subject", beat = "引き"},
]
```

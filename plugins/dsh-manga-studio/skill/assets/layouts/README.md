# コマ割りの型（図と解説）

`scripts/data/layouts.json` の型を 1 枚ずつ図にしたもの。右綴じで、丸数字は読む順、コマの中の語はそのコマで多い shot の目安、薄い青ははめ込み（上に重ねるコマ）。
根拠の数字は Manga109-s 全 87 冊のストーリー 15,458 ページを型に当てはめた集計（references/layout-library.md）。元の絵・台詞・作品名は持たない。

- `svg/<ID>.svg`・`png/<ID>.png`: 図
- `text/<ID>.md`: 解説とネーム TOML の雛形
- 作り直し: `python scripts/layout_assets.py`（layouts.json を変えたら流す）

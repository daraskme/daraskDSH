# Anima Base v1.0 のネイティブ LoRA 学習計画

## 対象と完了条件

DeepSeek Harness の通常の入口から画像とキャプションのフォルダーを指定し、シングル GPU で学習して ComfyUI が読み込める safetensors を得る。対象機は RTX PRO 6000 Blackwell Workstation Edition（97,887 MiB、SM 12.0）。現行の Anima 経路は diffusion-pipe の Cosmos Predict2 実装、DeepSpeed、PyTorch 2.9.1+cu128 を使う。実装は Opus 5.5 の設計レビュー後に GPT-6.2 Sol が行う。

## 実装順序と採否

1. 既存の画像とキャプションのスモーク素材で参照学習を固定する。Anima Base、Qwen3-0.6B、Qwen Image VAE、トークン化、LLM adapter、潜在表現の正規化、時間分布、flow target、LoRA 対象層・倍率、AdamW の設定を実コードと照合する。画像とテキストの前処理、モデルロード、反復、保存の時間を分けて記録する。
2. 第一候補は C++ と CUDA 対応 LibTorch。BF16 GEMM と attention の forward / backward は既存ライブラリで実行し、凍結重みでも各層の入力勾配は伝播させる。学習ループ、loss、勾配クリッピング、更新、出力までネイティブで動かす。モデル構造は参照実装から検証可能に移植またはエクスポートする。固定の VAE・テキスト条件は事前計算し、初回準備に必要なランタイムと所要時間も明記する。
3. GPU プロファイルで GEMM、attention、LoRA の小行列、同期・転送、再計算を切り分ける。96 GB に収まる条件で再計算とオフロードを外し、同じ設定の参照とも比較する。形状の揃うバケットで batched GEMM、融合更新、CUDA Graphs を候補にする。独自 CUDA、Triton、コンパイル済み PyTorch を比較候補とし、有効な高速化だけ採用する。
4. DSH の CLI から設定・実行・エラー・成果物を追えるようにする。既存のモデル設定と画像・キャプションを再利用する。未対応のモデルや設定は開始時に検出し、失敗・中断時に未完成の LoRA を公開しない。
5. 固定した latent、テキスト条件、noise、timestep、初期 LoRA で予測・loss・勾配・更新量を参照と比較する。複数ステップで勾配が下流から上流まで届くこと、凍結重みが変化しないことを確認する。実重みで保存した LoRA を ComfyUI に適用し、対象キー・スケールと固定入力での効果を確認する。
6. 同一 GPU・画像・解像度・バッチ・rank・精度で比較する。ウォームアップ後の反復時間の中央値と p95、画像/秒、ピーク VRAM、初回およびキャッシュありの総所要時間を記録する。512 と 1024 の代表条件を使い、設定変更による利得と言語・実装による利得を分ける。測定のばらつきと品質条件を踏まえて、最速と呼べる条件を限定する。

## レビュー依頼

速度を左右する仮定、C++/CUDA と他の言語・生成系を選ぶ根拠、Blackwell での実装上の落とし穴、比較条件、正しさの判定を敵対的に評価し、重大度順に修正事項を挙げること。実装開始前に採否を決める。

## Opus 5.5 の指摘を受けた実装方針

[設計レビュー全文](anima-native-opus-review.md) は計画書に対する独立レビュー。モデル ID は `claude-opus-5-5`。計算量と速度の概算は実測値と区別する。

- 実行形式はユーザー指定に合わせてネイティブを維持する。高速化の根拠は現行構成、再計算を外した現行構成、DeepSpeed を使わない eager / compile、ネイティブの実測から判断する。遅い条件も記録する。
- 反復は C++/ATen の自動微分、CUDA の SDPA・行列積と融合した更新を使う。画像を読むところから LoRA の公開までネイティブで実行できるよう、トークン化は既存の Hugging Face Rust 実装を使う。初回の学習環境のビルドと凍結 VAE・テキスト条件の変換は学習と分ける。
- 実際のベースは隠れ次元 2048、28 ブロック。学習対象は 448 個の線形層の A/B。既存プリセットは LLM adapter の LR が 0 なので、その出力をキャッシュできる。Qwen と T5 の両方のマスクを使い、最終条件は 512 トークンに揃える。
- 現行設定は BF16、logit-normal（shift なし）、ターゲットは noise − latent、FP32 MSE、全体の勾配ノルム上限 1、alpha = rank、AdamW の β は 0.9 / 0.99。現行の optimi の丸めと低精度更新も確認する。参照は diffusion-pipe リビジョン `c1159b4893e06a7a77446b5a3f72aa969836b3f9` の [モデル](../.runtime/diffusion-pipe/models/cosmos_predict2.py)、[学習設定](../.runtime/diffusion-pipe/train.py)。
- 初期 B が 0 の通常学習に加え、非ゼロの A/B で予測と勾配を検証する。ComfyUI の実モデルで対象層数、未適用キー、実効倍率、固定入力での予測変化を確認する。
